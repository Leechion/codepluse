# codepluse · Taste 视觉稿

类别：software / 多 Harness 桌面工作台。

Figma：https://www.figma.com/design/eNjOk5vGAqsntf5eqmGKpH?node-id=9-612

## 采用的设计原则

使用已安装的 `design-taste-frontend`（tasteskill 2.5.1）中的中性色占主导、单一强调色、统一样式体系、直白功能文案、真实产品界面和有目的的交互原则。用户指定原功能布局不变，因此不采用该技能为营销页准备的首屏、分屏章节、导航重排和展示动效。

视觉：Porcelain & Ink，暖白画布 `#FCFCFB`、石灰侧栏 `#F1F0ED`、墨色正文 `#242725`、次级文字 `#666B65`、细线 `#E0E2DC`、唯一强调蓝 `#2959B8`。主要动作采用墨色实心按钮，选中会话以白色表面和蓝色文字识别。

英文 Inter，中文 Noto Sans SC，终端与工具函数名 JetBrains Mono。主要消息正文 14px，控制和元信息维持桌面工作台密度。Figma 中颜色已绑定到 `codepluse / Taste · Porcelain & Ink` 变量集合。

## 保留的布局

- 320px 会话侧栏、原导航入口和文件夹/聊天/最近分组。
- 标签栏、会话目录/标题/标签/更多入口。
- 原消息顺序、工具卡片、输入框、模型/模式选择及发送入口。
- 原输入框下目录、分支、连接状态与上下文信息。
- 对话下方终端、右侧手动展开的辅助面板、全窗口底部状态栏。

修改前后检查了两个画板的 16 处主要区域，位置和尺寸差异为零。两张画板保留可编辑文字、矢量图标、自动布局和组件实例，没有完整 UI 的位图填充。

文字对比度：正文/画布 14.70:1；次级文字/侧栏 4.78:1；主按钮文字 15.09:1；蓝色/白色 6.53:1。

这是 Figma 视觉稿，未修改应用前端。Taste 的 HTML 浏览器 gate 不适用于 Figma 文件，因此没有报告网页 gate 通过。示例会话内容不代表服务端实时执行结果。
