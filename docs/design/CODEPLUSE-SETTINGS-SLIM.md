# 设置页第一批精简

2026-11-12。只调整界面入口和页面组合，未删除用户的配置、技能或快捷消息数据。

左侧从 15 类缩减为 10 类：外观、常规、协作、MCP、技能、智能体、浏览器操作、快捷键、版本控制、运行日志。版本控制和日志本轮仍保留独立入口。

- 移除外观页的桌面宠物、导入与市场模块，不再挂载宠物管理组件。
- 隐藏电脑操作、消息渠道和 Web 服务配置入口；原路径跳到常规页。协作页的电脑操作开关也隐藏，已有开关值不被其它工具设置的保存覆盖。
- 常规页集中日常偏好、快捷消息、语言与版本三个标签。新系统面板保留语言设置、版本和检查更新，不挂载未接通的代理、自启动、CLI 安装、云同步及备份恢复面板。
- 技能页集中“已安装 / 技能包”，保留各技能包原有分类和编辑功能。
- 标签页首次访问时加载，访问过的编辑器继续挂载，切换标签不丢失未保存草稿。

旧链接继续工作并保留查询参数（语言、remoteConnectionId、技能包 tab 等）：

| 原路径 | 新位置 |
| --- | --- |
| `/settings/system` | `/settings/general?view=system` |
| `/settings/quick-messages` | `/settings/general?view=quick-messages` |
| `/settings/skill-packs` | `/settings/skills?view=packs` |

验证：生产构建成功；相关六个测试文件共 44 项测试通过，包括导航精简、延迟挂载、草稿保留、重定向参数保留，以及隐藏电脑操作后不覆盖已保存值；修改的 TypeScript 文件通过 ESLint。8841 实际页面验证了常规三个标签、技能两个标签、旧技能包科研链接及系统链接跳转、外观页无宠物模块、协作页无电脑操作开关。未通过界面修改设置值或发送模型任务。
